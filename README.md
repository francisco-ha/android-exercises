# EjemplosAndroid
#  Android Exercises Playground

¡Bienvenido a mi repositorio de prácticas de Android! 

Este espacio funciona como mi laboratorio personal donde desarrollo diferentes aplicaciones para consolidar mis conocimientos en el desarrollo nativo con Kotlin.

## 📂 Proyectos en este repositorio

* [**POO_1 (Multi-App)**](./POO_1) - Una aplicación que funciona como un menú principal para acceder a múltiples mini-proyectos integrados. Demuestra el uso de **Arquitectura MVVM**, inyección de dependencias con **Dagger Hilt**, bases de datos locales con **Room**, consumo de APIs con **Retrofit**, y manejo de permisos, cámara y escáner QR.
